使用你自己的 API key（BYOK）

key 只保存在本浏览器的 localStorage，由页面直接发给 Google（Gemini）或 OpenRouter，不经过任何 AEOI 服务器，也不会写进仓库。在公用电脑上用完请点“忘记 key”。不填 key 也可以用 mock:demo 离线演示。

每次模型回合与工具调用会显示在这里：选择的工具、发送的请求 JSON、AEOI 响应（result / trust / warnings / error）、耗时与 token 用量。先试试模型 mock:demo（不需要 key）。


    

      
这是 AEOI 规范的端到端测试台的纯静态版本：18 个控制算子（Rust，编译为 WebAssembly）在你的浏览器里运行；Agent 循环也在浏览器里，模型由页面用你的 key 直接调用（Gemini Generative Language API 或 OpenRouter）。

      
与本地版（cargo run -p aeoi-web）的算子、函数声明、F-5 来源核对、系统提示词完全相同（同一套 Rust 代码）。浮点结果与 x86_64 原生版在约 3/4 的 golden 用例上逐位相同（lqr、lyap 全部逐位相同），其余差异 ≤ 1.5e-14（范数相对；多输入 place 的 K 不唯一），详见仓库 reports/parity-wasm-vs-native.json；平台标识为 wasm32-unknown。

      
参考值来自 python-control / scipy（不是 MATLAB）。
