# 10.34 `fit.poly.roots`：多项式求根（v0.4.20）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`fit.poly.roots` 0.4.0（容差类 T2）。

对应 MATLAB 的 `roots`。参考值来自 numpy.roots（未平衡的友矩阵，LAPACK 求特征值）；真值是 mpmath.polyroots 以 60 位精度对存储下来的 f64 系数求出的根，每个都用 60 位残差核对过。都不是 MATLAB 的结果。

这个算子逼出的问题有两个：

- **根的顺序。** MATLAB 按特征值求解器给出的顺序返回，不同实现、不同版本之间不可复现。
- **重根的精度。** m 重根只有约 u^(1/m) 的精度：(x − 1)² 的两个根算出来可能是 1 ± 4e-9i，看起来像一对复根。调用方需要知道哪些根不能单独相信，以及能相信的是什么。

**规范性条款**

- RT-1 **输入**：`p` 为 [n + 1] 实数，最高次在前。最高次的 0 系数去掉，发 `W.VALIDATION.LEADING_ZEROS_STRIPPED`（`details.removed`），次数按去掉后计。全为 0 报 `E.DOMAIN.ZERO_POLYNOMIAL`（新码）：零多项式处处为 0，根不确定。常数多项式（次数 0）没有根，返回空数组。次数上限 500，超出报 `E.VALIDATION.RANGE`。
- RT-2 **算法**：
  - 末尾的 k 个 0 系数给出 k 个精确的零根（`zero_roots` = k）。
  - 其余部分 q（次数 m）的根：Parlett–Reinsch 平衡（2 的幂，无舍入）后的友矩阵求特征值（任何后向稳定的非对称特征值算法均可；参考实现用 `kernels::schur` 的 Francis 双位移 QR），每个根至多 4 步 Newton 修正（只接受使 |q(z)| 下降的步）；共轭对保持精确共轭。这与 `control.lti.poles_zeros`、`signal.filter.filter` 的稳定性判定用的是同一个求根内核（11.5 RI-1；这一句只约束参考实现，PY-61）。
- RT-3 **顺序与类型**（作者决定，2026-11-26）：根总是以 c128 返回，按实部升序、实部相同时按虚部降序（与 `control.lti.poles_zeros` 相同）。另给 `real_count` 与 `all_real`；它们描述的是算出的根，簇内的实数重根可能被舍入分裂成一对共轭复根（见 RT-5）。
- RT-4 **包含半径**（作者决定）：每个根带 `error_radius`，真根一定落在这些圆盘的并里（`bound_kind = rigorous`；它是逐根的包含半径，一致性套件按 9.4 CF-7 的例外核查“真根在区域内”，不拿半径与验收容差比大小，PY-64）。依据是 Braess–Hadeler（1973）与 Carstensen（1991）的包含定理：
  - q 的根全在 ∪ D(z_i, m·|W_i|) 内，W_i = q(z_i)/(q_0·Π_{j≠i}(z_i − z_j))；k 个圆盘连成的分支恰好含 k 个根（计重数）。
  - 半径计入 q(z_i) 的舍入（复数 Horner，≤ γ_{4m+4}·q̃(|z_i|)）与乘积的舍入。
  - 两个近似值恰好相等时（Newton 修正可能把重根的两半推到同一个 f64），定理不能直接用：先把这 k 个值放到以它们为圆心、半径 max(|c|, 1)·u^(1/k) 的小圆上（角度 2πj/k），对放开后的点用定理，再把各半径加上放开的距离。
  - 孤立根（所在分支只有它一个）的 `error_radius` 是它的圆盘半径；簇内根的 `error_radius` 是到同簇最远点的距离（真根在簇的并里，位置不能再细分）。精确的零根半径为 0。
- RT-5 **根簇**：多于一个圆盘的分支是一个根簇（重根或密集根）。`multiplicity` 给出每个根所在分支的根数（孤立根为 1）。有根簇时发 `W.ACCURACY.CLUSTERED_ROOTS`（新码），`details.clusters` 给出每个簇的下标、根数、中心与半径，`details.unreliable_roots` 列出簇内各根的 JSON Pointer。簇内各根的位置不能单独依赖，簇的中心、半径与根数可以依赖。末尾 0 系数给出的 k 个精确零根不算簇：每个的 `error_radius` 为 0、`multiplicity` 为 k，不进入 `details.clusters`；q 的根的圆盘与 0 重叠时也不与它们合并（PY-62）。簇的 `center` 是簇内近似根的算术平均，`radius` = max_j(|z_j − center| + r_j)，因此簇的圆盘包含簇内每个圆盘（PY-63）。
- RT-6 **后置条件**：
  - `backward_stable`：逐根分量后向误差 max_i |q(z_i)|/q̃(|z_i|) ≤ 10·m·u，即每个根是系数相对扰动不超过该值的多项式的精确根。不成立时 `/roots`、`/error_radius` 不可依赖。
  - `radii_finite`：所有半径有限。不成立时 `/error_radius`、`/multiplicity` 不可依赖。
- RT-7 **输出**：`roots`（c128 [n]）、`error_radius`（[n]）、`multiplicity`、`degree`、`real_count`、`all_real`、`zero_roots`、`leading_zeros_removed`。
- RT-8 **确定性**：`platform_bitwise`。
