# 10.36 `linalg.matrix.det`：行列式（v0.4.22）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`linalg.matrix.det` 0.4.0（容差类 T2）。

对应 MATLAB 的 `det`。真值是 mpmath 以 80 位精度对存储下来的 f64 矩阵求出的行列式；n ≤ 8 的用例和所有奇异用例另用有理数精确计算（奇异用例的真值精确为 0）。numpy.linalg.det / slogdet 只作对照。都不是 MATLAB 的结果。

这个算子逼出的问题有两个：

- **溢出。** 150×150、元素量级 100 的矩阵，det ≈ e^991，MATLAB 与 numpy 都返回 Inf；0.1·I₁₀₀ 的 det 是 1e-100，完全良态，再小一些就下溢成 0。
- **奇异矩阵的 det 不是 0。** MATLAB 的 `det(magic(4))` 是 −1.4495e-12，看起来是一个“很小但非零”的数，常被误读为矩阵可逆。det 的大小与是否接近奇异无关；需要的是 det 的误差有多大。

**规范性条款**

- DT-1 **范围**：A 为实数方阵 [n, n]，n ≥ 1；非方阵、一维数组报 `E.VALIDATION.SHAPE`，复数报 `E.VALIDATION.DTYPE`（作者决定，2026-11-26）。
- DT-2 **算法**：LU 分解，部分选主元，与 10.19 LS-2 是同一内核（RI-1）。det = sign(P)·Π u_ii。乘积 MUST 分成尾数 m ∈ [0.5, 1) 与二进制指数 e 累乘：每一步把 |u_kk| 精确拆成尾数与指数，尾数相乘（一次舍入）后再精确拆开。因此中途不会溢出或下溢，舍入次数是 n。`log_abs_det` = ln m + e·ln 2（超越函数按 M-7a），`sign` ∈ {−1, 0, 1}。原因：先乘后取对数会在 e^709 溢出；逐个取对数再相加多 n 次 log 的误差。
- DT-3 **超出范围**（作者决定，2026-11-26）：|det| 超出 f64 的正规数范围时，`det` 为 `"Inf"` / `"-Inf"` 或下溢后的值（可能为 0），MUST 发 `W.NUMERICAL.DET_OUT_OF_RANGE`（新码），`log_abs_det` 与 `sign` 仍然有效。
- DT-4 **误差估计与“与零不可区分”**（作者决定，2026-11-26）：
  - `relative_error_estimate` ε = n·u·est(‖A⁻¹‖₁)·‖|L|·|U|‖₁ + n·u。est 是 Hager–Higham 1-范数估计（与 LS-5 同一实现）；‖|L||U|‖₁ 以 O(n²) 算出（先求 |L| 的列和，再乘 |U|）。依据：LU 的后向误差 |E| ≲ n·u·|L||U|，经 det(A + E) ≈ det(A)·(1 + tr(A⁻¹E)) 传到 det，再加上乘积的 n 次舍入。它是启发式的一阶界（`bound_kind = a_posteriori_heuristic`），不是严格上界。
  - ε ≥ 1，或某步主元恰为 0（此时 `det = 0`、`sign = 0`、`log_abs_det = "-Inf"`、ε = `"Inf"`）时，`zero_within_error = true`，MUST 发 `W.NUMERICAL.DET_NOT_SIGNIFICANT`（新码），后置条件 `significant` 不成立，`/det`、`/sign`、`/log_abs_det` 列为不可依赖（E-13）；`relative_error_estimate` 与 `zero_within_error` 本身仍可依赖。
  - 一致性套件核查这个声明：真值精确为 0 的用例上 `zero_within_error = false` 是虚报。
  - golden 上 15 个非奇异用例里，估计都不小于实际误差；三个奇异用例（`magic(4)`、秩 1、秩 3 的整数矩阵）都被标出。
- DT-5 **输出**：`det`、`sign`、`log_abs_det`、`relative_error_estimate`、`zero_within_error`、`method`（`lu_partial_pivoting`）。
- DT-6 **确定性**：`platform_bitwise`。

判断矩阵是否奇异或接近奇异 SHOULD 用条件数（`linalg.matrix.inv` 或 `linalg.system.solve` 的 rcond），不要看 det 的大小（manifest 的 `not_for` 写明）。

新码：`W.NUMERICAL.DET_NOT_SIGNIFICANT`、`W.NUMERICAL.DET_OUT_OF_RANGE`。
