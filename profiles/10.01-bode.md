# 10.1 `control.lti.bode`

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`control.lti.bode` 0.2.0（容差类 T3）。


对应 MATLAB 的 `bode`。参考值来自 python-control 0.10（`frequency_response`），不是 MATLAB 的结果。

**规范性条款**（v0.4.21 起编号；之前是“语义要点”）

- BD-1 **频点**：
  - `explicit`：`values` MUST 严格递增（相位展开依赖顺序），否则 `E.VALIDATION.GRID`，path 指向第一个不大于前一个点的位置；补丁把 `values` 换成升序排序并去重后的数组（去重后仍有问题，例如落在极点上，由后续检查另行报告）。
  - `logspace`：`min < max`，否则 `E.VALIDATION.RANGE`，补丁交换两者。点为 10^(a + (b − a)·k/(n − 1))，k = 0…n − 1，a = log10(min)，b = log10(max)，**先在输入单位里生成，再换算**。
  - 单位：`Hz` 时每个点乘以 2π；输出的 `w` 一律 rad/s。
  - 离散系统：任一点 > (π/ts)·(1 + 1e-12) 报 `E.DOMAIN.ABOVE_NYQUIST`。补丁：`explicit` 时删去这些点，`logspace` 时把 max 设为 Nyquist 频率（换回输入单位）。
- BD-2 **求值**：评估点 s = jω（连续）或 e^{jωts}（离散）。
  - tf：Horner，带 Higham（2002 §5.1）的一阶误差界：分子、分母各 γ_{2·len}·Σ|a_k||s|^k / |值|，之和再加 u。
  - zpk：乘积形式 k·Π(s − z)/Π(s − p)，误差界 Σ u(|s| + |r|)/|s − r| + (n_z + n_p + 1)u。
  - ss：逐频点复 LU 解 (sI − A)X = B，G = CX + D。n ≤ `limits.max_states_for_svd_condition` 时，用 SVD 求 κ₂(sI − A)，估计 4·n·u·κ₂（启发式，不是严格界）；n 更大时不估计。
- BD-3 **频点落在极点上**：tf 分母为 0 或其相对误差界 ≥ 1/2；zpk 某个 |s − p| 为 0 或 u(|s| + |p|)/|s − p| ≥ 1/2；ss 的 LU 失败，或（有估计时）κ₂·u·n ≥ 1/2。这些情形报 `E.NUMERICAL.POLE_ON_GRID`，path 指向该频点，没有补丁（极点处没有有限值；用户可以去掉或微移该点）。
- BD-4 **频点落在零点上**：响应恰为 0 时，幅值记 `"-Inf"` dB，相位记 `"NaN"`，发 `W.NUMERICAL.ZERO_ON_GRID`。
- BD-5 **误差估计与警告**：逐频点的相对误差界或估计（BD-2），其最大值 > 1e-6（**相对误差**，不是 dB 或度）时发 `W.NUMERICAL.NEAR_POLE`，`details` 给出该频点与估计值。dB 误差约为 8.686 × 相对误差，相位误差（度）约为 57.3 × 相对误差。manifest 的 `exactness.bound_kind` 是 `a_posteriori_heuristic`：一个方法对不同输入的界强弱不同时（tf、zpk 是先验界，ss 是启发式估计），manifest 写其中最弱的那个，每个响应的 `trust.error_estimate.basis` 写明本次用的是哪一种。
- BD-6 **相位约定**：`branch_center_deg = c`（缺省 0）。
  - `unwrap = true`（缺省）：第一个频点的相位取 (c − 180, c + 180] 内的主值；之后每点取“与前一点 atan2 之差”的主值，累加到前一点的相位上（与 `numpy.unwrap` 一致）。
  - 响应为 0 的频点（BD-4）相位为 NaN，**不更新**展开的参考值：下一个非零频点仍与最近一个非零频点比较。
  - `unwrap = false`：每点都落在 (c − 180, c + 180] 内。
  - MIMO 按通道独立展开。
- BD-7 **输出与后置条件**：`w`（rad/s）、`magnitude_db`、`phase_deg`，按通道 [ny][nu]。后置条件 `all_finite`（全部幅值与相位有限；频点落在零点上时它为 false）与 `frequencies_strictly_increasing`。
- BD-8 **确定性**：`platform_bitwise`。
