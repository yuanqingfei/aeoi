# 10.33 `fit.poly.polyval`：多项式求值（v0.4.20）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`fit.poly.polyval` 0.4.0（容差类 T1）。

对应 MATLAB 的 `polyval`。参考值有两个：numpy.polyval（普通 Horner，与 MATLAB 相同的算法），以及在存储下来的 f64 点上用有理数精确算出的多项式值（真值）。都不是 MATLAB 的结果。

这个算子逼出的问题：在重根附近，普通 Horner 一位有效数字也不剩。例如 (x − 1)⁶ 展开后在 x = 1.001 求值，真值 1e-18，numpy 给出 −2.2e-15，连符号都错。可以用补偿算法把精度提高到“二倍精度算完再舍入”，再给每个点一个严格的误差界，让调用方知道剩下几位。

**规范性条款**

- PV-1 **输入**：
  - `p`：[n + 1] 实数，最高次在前（同 MATLAB、numpy）。最高次的 0 系数保留（只是让次数虚高，不影响值）。次数上限 1000，超出报 `E.VALIDATION.RANGE`。
  - `x`：[q] 实数。复数 x 报 `E.VALIDATION.DTYPE`，提示传递函数的频率响应用 `control.lti.bode`：本版的误差界只对实数补偿 Horner 证明过。
  - `mu`（可选）：`fit.poly.polyfit`（`scaling = center_scale`）返回的 [mean, std]。给了就在 t = (x − mu[0])/mu[1] 处求值，t 在 f64 里算一次（同 MATLAB `polyval(p, x, [], mu)`）。std 为 0 或非有限时报 `E.VALIDATION.RANGE`。
- PV-2 **算法**（作者决定，2026-11-26）：补偿 Horner（Graillat、Langlois、Louvet 2005）。每一步 s·t + a_i 用 TwoProduct（Dekker 拆分）与 TwoSum 求出精确的舍入误差，误差用另一条 Horner 递推累加，最后加回。不用 FMA，所以各平台逐位相同。结果与“用二倍精度算完再舍入”一样准：|y − p(t)| ≤ u|p(t)| + γ_{2n}²·p̃(|t|)，p̃(t) = Σ|a_i|t^i。
- PV-3 **逐点误差界**：`error_bound` = (u|y| + γ_{2n}²·p̃/(1 − γ_{2n}))/(1 − u)·(1 + 4u)。它是严格的（`bound_kind = rigorous`）：覆盖了上式中未知的 |p(t)| 以及计算 p̃ 和界本身的舍入。不考虑下溢（结果量级在 1e-290 以上时成立）。界针对给定的 f64 系数和 f64 的 t；系数本身的误差由 `condition` = p̃(|t|)/|p(t)| 放大传到结果上。
- PV-4 **少于 8 位有效数字时警告**：y ≠ 0 且 `error_bound` > 1e-8·|y| 的点，发 `W.NUMERICAL.ILL_CONDITIONED`，`details` 给出这样的点数与下标。算得恰为 0 的点不警告：这时 `error_bound` 本身就是“|p(t)| 不超过多少”的回答。
- PV-5 **溢出**：某点上值或误差界不是有限数时，报 `E.NUMERICAL.NON_FINITE_EVALUATION`，path 指向该点 `/x/data/{k}`，提示可先用 `center_scale` 拟合再带 mu 求值。
- PV-6 **输出**：`y`、`error_bound`、`condition`（均为 [q]）、`degree`（= 系数个数 − 1）、回显的 `mu`。
- PV-7 **后置条件 `horner_consistent`**：普通 Horner 的值与本结果之差 ≤ γ_{2n}·p̃/(1 − γ_{2n})·(1 + 4u) + `error_bound`，两种算法的误差界之和。不成立时 `/y`、`/error_bound` 不可依赖。
- PV-8 **确定性**：`platform_bitwise`。
