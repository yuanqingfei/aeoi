# 10.23 `linalg.decomp.svd`：奇异值分解（v0.4.11）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`linalg.decomp.svd` 0.4.0（容差类 T1）。


对应 MATLAB 的 `svd`。真值是 mpmath 以 50 位精度给出的奇异值与奇异向量，numpy（LAPACK `dgesdd`）的值只作记录。都不是 MATLAB 的结果。

**规范性条款**

- SV-1 **模式**：
  - `values`：只要奇异值。
  - `thin`：缺省，同 MATLAB `svd(A, "econ")`，U 为 [m, p]、V 为 [n, p]，p = min(m, n)。
  - `full`：U、V 为方阵；补全部分是 thin 因子的 Householder QR 给出的正交补，前 p 列保持不变。

  返回 V 而不是 Vᵀ（同 MATLAB；numpy 返回 Vᵀ）。
- SV-2 **算法**：单边 Jacobi（Hestenes），m < n 时作用在 Aᵀ 上；|g_pᵀg_q| > sqrt(m)·ε·‖g_p‖‖g_q‖ 时旋转，至多 60 轮扫描；σ_k = ‖g_k‖₂。两个阈值（v0.4.25 写明，第二实现 PY-68）：
  - **旋转下限**：‖g_p‖ 或 ‖g_q‖ ≤ max(m, n)·ε²·‖A‖_F 时这一对不旋转。原因：精确秩亏矩阵的舍入残余列与某个大列几乎平行，每次旋转只缩小约 ε 倍，余弦却仍接近 1，判据永远成立；v0.4.24 及以前的参考实现能停下来，只是因为未缩放的平方和下溢成 0，照字面写的第二实现在 4×9 的秩 1 矩阵上 60 轮不收敛。下限取 ε² 而不是 ε，是为了让真实的小奇异值（低到约 1e-31·‖A‖_F）照常参与旋转，保留 Jacobi 对分级矩阵的相对精度。
  - **数值零**（v0.4.23）：σ_k ≤ max(m, n)·ε·σ_max 时，对应的 u_k 由正交补全给出，不用 g_k/σ_k（那是舍入残余，未必与别的列正交；4×9 的秩 1 矩阵上曾得到两列平行的 V）。
  - 先试过 nalgebra 的双对角 QR：在行分级矩阵（行尺度 1e8 : 1 : 1e-8）上重构残差为 8.7e-10，中间一行的信息丢了。后置条件 `reconstructs` 如实报了不成立，所以换成 Jacobi，重构残差降到 2.5e-16。
  - 在 400×400 上耗时约 2 秒，因此 `limits.max_dimension` 为 500。
- SV-3 **符号**（作者决定）：u_k 中模最大的分量（并列取下标最小）为正，v_k 随之变号。
- SV-4 **数值秩**：s_k > max(m, n)·eps(s_max) 的个数，eps(x) 为 |x| 到下一个更大 f64 的距离：|x| ∈ [2^e, 2^(e+1)) 时为 2^(e−52)，x 恰为 2 的幂时取向上的间距（同 MATLAB `eps`、numpy `spacing`）；eps(0) = 2⁻¹⁰⁷⁴（最小次正规数）（v0.4.25 写明，PY-69）。输出 `rank`、`rank_tol`、`cond2` = s_max/s_min（s_min = 0 时为 "Inf"）。
- SV-5 **后置条件**：`reconstructs`（‖A − U·diag(s)·Vᵀ‖_F/‖A‖_F）、`orthonormal_u`、`orthonormal_v`（‖UᵀU − I‖_max 等）都 ≤ 100·max(m, n)·u；外加 `all_finite`。相对残差的分母为 0 时（零矩阵、秩 0）取分子本身，即绝对残差（PY-67）。`values` 模式也在内部检查。
- SV-6 **误差估计**：|Δs_k| ≲ ‖A‖_F·残差 + s_max·正交性误差（Weyl）。小奇异值只有绝对精度，没有相对精度。奇异向量夹角 ≲ 该界/gap_k（Wedin）。
- SV-7 **确定性**：`platform_bitwise`。
