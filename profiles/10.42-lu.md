# 10.42 `linalg.decomp.lu`：LU 分解（v0.4.24）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`linalg.decomp.lu` 0.4.0（容差类 T1）。

对应 MATLAB 的 `[L, U, P] = lu(A)`。真值是 mpmath 以 50 位精度对**存储下来的 f64 数据**求出的分解。不是 MATLAB 的结果。LU 的真值由生成脚本按同一选主元规则逐步求出；候选主元相差不到相对 1e-8 又不精确相等的用例（例如 Hilbert 矩阵）被拒收，因为那时置换取决于舍入。

这一组三个算子（10.42 – 10.44）把其他算子早已在用的分解直接交给调用方：LU 是 `linalg.system.solve`、`inv`、`det`、`cond` 的内核，QR 是最小二乘与 `polyfit` 的内核，Cholesky 是 `lqr`、`dlqr` 的内核（RI-1）。它们逼出的是**输出约定**：置换怎么表示，经济型还是完整型，不唯一的符号怎么定。这些在 MATLAB、numpy、LAPACK 之间各不相同，不写死就无法比较两个实现。

**规范性条款**

- LU-1 **范围**（作者决定，2026-11-26）：A 为实数方阵 [n, n]；非方阵报 `E.VALIDATION.SHAPE`（矩形 LU 以后考虑），复数报 `E.VALIDATION.DTYPE`。
- LU-2 **算法与置换**：部分选主元，每列取 |a_ik| 最大的第一行（LAPACK dgetf2 顺序），MUST 与 10.19 LS-2 同一内核。`perm` 是 0 起始的整数数组（作者决定），A[perm, :] = L·U，即 P·A = L·U 中 P 的第 i 行是 e_{perm[i]}ᵀ；不返回 n×n 的置换矩阵。`perm_sign` = det(P)。
- LU-3 **奇异矩阵**：某步主元恰为 0 时该列在对角线以下已全为 0，消元跳过，U 的该对角元为 0。分解仍然成立并照常返回（同 MATLAB），MUST 发 `W.NUMERICAL.ZERO_PIVOT`（新码），`zero_pivot` 给出第一个这样的步。
- LU-4 **后置条件 `reconstructs`**：‖A[perm, :] − L·U‖_F/‖A‖_F ≤ 100·n·u，残差用补偿算术算。部分选主元在增长因子大时不是后向稳定的；`growth_factor` = max|u_ij|/max|a_ij| 作为结果字段返回，残差超过阈值时 L、U、perm 不可依赖（E-13）。golden 上 Wilkinson 矩阵（n = 40）的增长因子是 2³⁹，但因子都是 2 的幂，分解精确，残差为 0。
- LU-5 **确定性**：`platform_bitwise`。
