# 10.41 `linalg.matrix.cond`：条件数（v0.4.23）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`linalg.matrix.cond` 0.4.0（容差类 T2）。

对应 MATLAB 的 `cond`。真值是 mpmath 以 50 位精度对**存储下来的 f64 数据**求出的结果；numpy.linalg 只作对照。都不是 MATLAB 的结果。

**规范性条款**

- CN-1 **范围**：p = 2（缺省）时 A 可以是任意 [m, n]；p ∈ {1, "inf", "fro"} 时 A MUST 是方阵，否则报 `E.VALIDATION.SHAPE`，remediation 给 p = 2 的补丁（`requires_user_confirmation: true`）。
- CN-2 **算法**：p = 2：cond = σ_1/σ_min（与 `linalg.decomp.svd` 同一内核），σ_min = 0 时为 `"Inf"`。其余 p：cond = ‖A‖_p·‖A⁻¹‖_p，A⁻¹ MUST 与 `linalg.matrix.inv` 同一算法（参考实现 `kernels::dense::inverse_refined`）。
- CN-3 **奇异**：LU 某步主元恰为 0 时 cond = `"Inf"`、rcond = 0（同 MATLAB）。
- CN-4 **输出与误差**：`cond`、`rcond` = 1/cond、`p`、`relative_error_estimate`（p = 2：Weyl 界 e/σ_min + e/σ_max；其余：κ·η，η 为求逆的后向误差；都是启发式的）。σ_min 只有绝对精度，所以 cond 的相对误差约为 u·cond：Hilbert 6 的 2-范数条件数误差 8e-11，Hilbert 13 是 0.36（估计 1.3e4，只有量级有意义）。rcond < ε 时发 `W.NUMERICAL.ILL_CONDITIONED`。
- CN-5 **后置条件** `decomposition_checked`：p = 2 为 SVD 的重构与正交性；其余为求逆的后向误差 η ≤ 10·n·u。
- CN-6 **确定性**：`platform_bitwise`。

大矩阵只需要知道是否病态时，SHOULD 用 `linalg.system.solve` 或 `linalg.matrix.inv` 结果里的 rcond，不必另算条件数。
