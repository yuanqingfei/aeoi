# 10.4 `control.lti.convert`（v0.3 新增）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`control.lti.convert` 0.3.0（容差类 T2）。


tf ↔ ss ↔ zpk 互转。下面的条款是本算子的规范性定义（v0.4.21 起编号；此前是不编号的“语义要点”，第二实现第二轮 PY-42、PY-57 – PY-60 指出它们不足以定义行为）。

- CV-1 **输入与目标**：`to ∈ {tf, ss, zpk}`。输入按 3.1 T-5、T-6 解析：非 proper 的输入（tf 分子阶次高于分母，zpk 零点多于极点）在解析阶段就返回 `E.DOMAIN.IMPROPER_SYSTEM`，**与目标表示无关**（包括 `to = tf`、`to = zpk`）。原因：v0.4 的 `LtiSystem` 值按定义是 proper 的（T-5），只有组合算子的多项式路径例外（I-7）；让 convert 接受 improper 输入会产生一个别的算子都不接受的值。`to` 与输入同类时原样返回，`realization = identity`。
- CV-2 **各路径与 `realization`**（R-6）：

  | 路径 | 方法 | `realization` |
  |---|---|---|
  | tf→ss（SISO） | 可控标准型（R-6 的 scipy `tf2ss` 约定） | `controllable_canonical` |
  | tf→ss（MIMO） | 每个元素 (i, j) 先按可控标准型实现，块按 (i, j) **行主序**排在 A 的对角线上；块 (i, j) 的 B 只占第 j 列，C 只占第 i 行，D[i][j] 取该元素的直通项 | `block_diagonal_controllable_canonical` |
  | zpk→ss | 先乘积展开成 tf（同 zpk→tf），再用可控标准型 | `controllable_canonical` |
  | ss→tf | R-7（所有元素共享 det(sI − A)） | `ss2tf_characteristic_polynomial` |
  | zpk→tf | 乘积展开：num = k·Π(s − zᵢ)，den = Π(s − pᵢ)，取实部 | `expanded_product` |
  | tf→zpk | 分子、分母分别求根（平衡友矩阵特征值 + Newton 精修，共轭对精确共轭）；k = 分子首项 / 分母首项 | `polynomial_roots` |
  | ss→zpk | 极点 = eig(A)，零点 = 不变零点（R-9 的约化），k 按 R-8 | `invariant_zeros_eigenvalues_markov_gain` |

  原因：同一个 G 有无穷多个实现；不写死块的顺序与位置，两个正确实现返回的 `A` 就不同，比较只能退回不变量（PY-37）。
- CV-3 **非最小实现警告**：结果的阶次可能高于最小阶次时 MUST 发 `W.DOMAIN.NONMINIMAL_REALIZATION`（`path: /system`）。具体是两种情形：MIMO tf→ss（块对角，每个元素各自一份状态），以及 MIMO ss→tf（共享分母 det(sI − A) 后，各元素的分子分母一般有公因子）。SISO 路径不发。v0.4 不做零极点对消（R-6）。
- CV-4 **zpk 只表示 SISO**（R-8）：`to = zpk` 而输入是 MIMO 时返回 `E.DOMAIN.MIMO_NOT_SUPPORTED`（`path: /to`），remediation 给 `to: "tf"` 与 `to: "ss"` 两个补丁。
- CV-5 **恒为零的传递函数**：SISO 输入的 G(s) ≡ 0 时（ss 输入按 R-9 的法秩检验判定；tf 输入是分子为 [0]），`to = zpk` 返回 `k = 0`、`z = []`、`p` 为分母的根（ss 输入为 eig(A)）。这不违反 R-9：R-9 约束的是“求零点”的算子（`poles_zeros`），返回的是零点集合；convert 返回的是一个表示，k = 0 的 zpk 已经完整表示了 G ≡ 0，`z` 不被解释为“系统没有零点”。R-9 的约化没有得到方的、可逆的约化直通矩阵时（SISO 上只可能是数值原因），返回 `E.DOMAIN.DEGENERATE_SYSTEM`。
- CV-6 **前导零与归一化**：T-6 的 `W.VALIDATION.LEADING_ZEROS_STRIPPED` 只针对输入；R-7 在 ss→tf 中去掉的前导零不发警告。`normalize = true`（默认）时，返回的每个 tf 分母为首一（分子、分母同除分母首项）；对 ss→tf、zpk→tf 不起作用（分母本来就首一）。`normalize = false` 只影响 tf→tf。
- CV-7 **一致性检查与 trust**：转换前后在 9 个测试点比较频率响应。连续系统：s_k = j·ω_k，ω_k = 10^(−2 + k/2)·S（k = 0…8），S = max(1, max|p|)，p 为输入系统的极点；离散系统：z_k = e^{jθ_k}，θ_k = min(10^(−2 + k/2), 3)。与输入系统某个极点的距离小于 1e-6·max(1, |s_k|) 的点跳过。每点的差为 max|G_in − G_out| / max|G_in|（逐元素取模，分母不小于 1e-300），`residual.response_max_rel_discrepancy` 是 9 点中的最大值（全部跳过时为 null）。它 > 1e-6 时 MUST 发 `W.NUMERICAL.CONVERSION_DISCREPANCY`，后置条件 `response_consistent` 为 false（E-12；coverage `test_points`）；全部跳过时 `response_consistent` 为 true（没有可比的点）。原因：多项式系数与根对扰动敏感（重根、高阶），这一检查是对“转换没有改变系统”的唯一独立证据。阈值 1e-6 与组合算子 I-9 的 1e-5 不同：组合算子多一步互联运算。
- CV-8 **一致性判定**（9.4）：比较的是系统而不是系数。套件从请求独立重算：在 CV-7 的测试点上，被测结果相对**输入系统**的频率响应差 d_impl MUST 不大于 max(1e-8, 10·d_ref)，d_ref 是 golden 期望系统相对输入系统的同一差值（容差来自套件与参考，不来自被测实现的自报值，CF-6）。另外检查输出的 `kind` 等于 `to`、`ts` 不变、`realization` 与 CV-2 一致，ss 结果的状态数等于 golden 期望系统的状态数。原因：同一系统的系数可以因为归一化或舍入而不同，响应才是不变量；以输入为基准，也就不依赖参考系数本身的舍入。
