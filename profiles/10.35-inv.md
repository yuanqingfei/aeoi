# 10.35 `linalg.matrix.inv`：逆矩阵（v0.4.22）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`linalg.matrix.inv` 0.4.0（容差类 T1）。

对应 MATLAB 的 `inv`。真值是 mpmath 以 80 位精度对**存储下来的 f64 矩阵**求出的逆（n ≤ 8 时另用有理数精确求逆，两者逐位相同）；numpy.linalg.inv（LAPACK `dgetrf` + `dgetri`）只作对照。都不是 MATLAB 的结果。

这个算子逼出的问题与 `linalg.system.solve` 相同：结果能信多少。MATLAB 的 `inv(hilb(13))` 只打印一行警告就返回一个矩阵，那个矩阵一位有效数字也没有。这里调用方从信封里就能看到：条件数是结果字段，结果没有有效数字时 `/X` 被列为不可依赖。

**规范性条款**

- IV-1 **范围**：A 为实数方阵 [n, n]，n ≥ 1。非方阵、一维数组报 `E.VALIDATION.SHAPE`（remediation 指向 `linalg.matrix.pinv` 与 `linalg.system.solve`）；复数报 `E.VALIDATION.DTYPE`，0.4.0 不支持（作者决定，2026-11-26，与 10.19 一致）。
- IV-2 **算法**：LU 分解，部分选主元，规则与 10.19 LS-2 相同，并且 MUST 是同一内核（11.5 RI-1：参考实现是 `kernels::dense::lu_factor`）。某步主元恰为 0 报 `E.NUMERICAL.SINGULAR`（remediation 为 `ask_user`）。X 的第 j 列解 A·x_j = e_j；`refinement = auto`（缺省）时每列按 LS-2 做至多 3 步迭代精化（参考实现与 `linalg.system.solve` 共用 `kernels::dense::lu_solve_refined`），`none` 时每列只解一次。原因：逐列精化使每一列都是后向稳定的；golden 上 Hilbert 10（κ₁ = 3.5e13）的逆与真值逐位相同，numpy 的相对误差是 2.3e-6。
- IV-3 **后向误差与后置条件 `backward_stable`**：η = max_j ‖e_j − A·x_j‖∞ / (‖A‖∞‖x_j‖∞ + 1)（逐列 Rigal–Gaches 范数后向误差，残差用补偿算术），要求 η ≤ 10·n·u。不成立时 `/X` 不可依赖（E-13）。
- IV-4 **条件数与后置条件 `forward_error_below_one`**：κ₁ = ‖A‖₁·‖X‖₁，用返回的 X 直接算（不是估计），作为结果字段 `kappa1` 返回，`rcond` = 1/κ₁。
  - rcond < ε 时 MUST 发 `W.NUMERICAL.ILL_CONDITIONED`，`details` 给出 rcond 与 κ₁，**仍返回结果**（作者决定，2026-11-26，与 MATLAB 和 LS-5 相同）。
  - 后置条件 `forward_error_below_one`：一阶前向误差估计 κ₁·η < 1。不成立时 `/X` 不可依赖（E-13）。原因：rcond < ε 只说明“可能”没有有效数字；κ₁·η ≥ 1 说明一阶估计本身已经不能保证任何一位，结果不应被引用。
  - 一致性套件核查这个声明：真值的 κ₁·u ≥ 10 的用例上声明 `forward_error_below_one = true` 是虚报。
- IV-5 **输出**：`X`（[n, n]）、`kappa1`、`rcond`、`method`（`lu_partial_pivoting`）、`refinement_steps`（各列实际加上的修正步数的最大值）。`refinement` 回显在 `trust.derived.refinement`（与 LS-6 相同的理由）。后置条件另有 `all_finite`。
- IV-6 **确定性**：`platform_bitwise`，只用 f64 加减乘除（M-7a）。

解方程组时 SHOULD 用 `linalg.system.solve`，不要先求逆再相乘：多一倍的运算量，结果也更不准（manifest 的 `not_for` 写明）。
