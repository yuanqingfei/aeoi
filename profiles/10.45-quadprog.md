# 10.45 `optim.quadratic.quadprog`：凸二次规划（v0.4.26）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`optim.quadratic.quadprog` 0.4.0（容差类 T1）。

对应 MATLAB 的 `quadprog`。真值由生成脚本枚举不等式约束（含边界）的每个子集、以 mpmath 50 位解各自的 KKT 方程组得到：H 正定时，原始可行且乘子非负的子集恰有一个，与任何有效集迭代的路径无关。退化的最优点（起作用约束的乘子或不起作用约束的松弛接近 0）不收。不是 MATLAB 的结果。

这个算子逼出的问题是：“最优”在什么时候是全局的。fmincon（10.29）只能保证局部最优；严格凸的二次规划不同，最优解唯一且是全局的，结果应当这样说，而且能用 KKT 条件完全验证。

**规范性条款**

- QP-1 **问题与凸性**（作者决定，2026-11-26）：min ½xᵀHx + fᵀx，s.t. A·x ≤ b、Aeq·x = beq、lb ≤ x ≤ ub，输入格式与 `linprog`（LP-1）相同，H 每行一个数组。H MUST 正定：用 Cholesky 检验（与 `linalg.decomp.chol` 同一内核，RI-1），失败报 `E.DOMAIN.NOT_POSITIVE_DEFINITE`（details 给出失败的列与主元，remediation 为 `ask_user`）。半正定与不定的 H 以后作为另外的方法。
- QP-2 **对称化**（作者决定，2026-11-26）：H 不对称时 MUST 按 (H + Hᵀ)/2 求解，结果回显 `symmetrized`；不对称超出 10·n·u·max|h_ij| 时发 `W.VALIDATION.SYMMETRIZED`。原因：½xᵀHx 只取决于对称部分，所以问题不变（与 `chol` 的 CH-2 不同：那里不对称意味着分解的对象不确定）。
- QP-3 **算法与乘子**：有限的 lb、ub 化为不等式行。原始有效集法，可行起点由 LP 内核（零目标）给出，每步的 KKT 系统用 LU 内核，工作集的独立性用 QR 内核（同 fmincon 的子问题，RI-1）。乘子按 MATLAB 的分组与符号：Hx + f + Aᵀλ_ineqlin + Aeqᵀλ_eqlin − λ_lower + λ_upper = 0，除 `eqlin` 外都 ≥ 0（同 LP-3）。约束不相容报 `E.DOMAIN.INFEASIBLE`；有效集迭代到上限报 `E.NUMERICAL.NO_CONVERGENCE`。
- QP-4 **后置条件 `kkt`**：原始可行、对偶可行、互补、驻定的残差都 ≤ 1e-9。驻定与互补以 max(1, ‖Hx + f‖∞, ‖f‖∞) 归一，原始可行以 max(1, |右端|) 归一。另有 `all_finite`。
- QP-5 **输出**：`x`、`fval` = ½xᵀHx + fᵀx、`lambda`（`ineqlin`、`eqlin`、`lower`、`upper`）、`iterations`、`bounds_used`、`symmetrized`。`derived.optimum` = `global`。
- QP-6 **确定性**：`platform_bitwise`。
