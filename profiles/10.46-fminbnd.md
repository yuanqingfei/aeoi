# 10.46 `optim.scalar.fminbnd`：有界单变量极小（v0.4.26）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`optim.scalar.fminbnd` 0.4.0（容差类 T2）。

对应 MATLAB 的 `fminbnd`。真值是 f 在区间上的**全部**局部极小点（mpmath 50 位：从 400 个起点对 f′ 求根，取 f″ > 0 的；端点处 f 向内增大时端点也算），每个都用相邻点的函数值核对。不是 MATLAB 的结果。

这个算子逼出的问题与 fmincon 相同：结果只是局部极小，MATLAB 不提醒。区别是一维区间上可以便宜地抽查：探测 103 个点就能发现大多数“另一个更深的谷”。

**规范性条款**

- FB-1 **问题**：f 用 3.15 的表达式语言写（变量名缺省 x，可带参数，与 `fzero` 相同）；`interval` = [x1, x2] MUST 有限且 x1 < x2，否则报 `E.VALIDATION.RANGE`（顺序反了时给交换两端的补丁）。
- FB-2 **算法**：Brent 极小化（Brent 1973 Ch. 5；Forsythe–Malcolm–Moler fmin；MATLAB fminbnd 的算法），参考实现是 `kernels::bracket::fmin`：c = (3 − √5)/2，起点 x = v = w = x1 + c(x2 − x1)；tol1 = √ε·|x| + tol_x/3，tol2 = 2·tol1；|x − (a + b)/2| ≤ tol2 − (b − a)/2 时停止；抛物步满足 |p| < |q·r/2| 且落在 (a, b) 内时采用，离端点不足 tol2 时改为向中点走 tol1，否则黄金分割步；步长至少 tol1。端点本身不被求值（同 MATLAB）。f 在某次求值上不是有限值时报 `E.NUMERICAL.NON_FINITE_EVALUATION`；求值次数超过 `max_evaluations` 报 `E.NUMERICAL.NO_CONVERGENCE`，details 给出目前最好的点。
- FB-3 **容差**（作者决定，2026-11-26）：缺省同 MATLAB，`tol_x` = 1e-4、`max_evaluations` = 500，两者都回显。Brent 方法在光滑的极小点附近最多达到约 √ε·|x| ≈ 1.5e-8·|x|，再小的 `tol_x` 不会更准。
- FB-4 **局部与全局**（作者决定，2026-11-26）：Brent 结束后，在 x1 + k(x2 − x1)/100（k = 0 … 100，含两端点）上求 f。有探测点 p 满足 f(p) < f(x) 且 |p − x| 大于一个网格步长时，MUST 发 `W.ACCURACY.BETTER_POINT_FOUND`（新码），details 给出 f 最小的那个探测点；后置条件 `grid_probe` 不成立，`/x`、`/fval` 不可依赖。`grid_probe` 的覆盖是 `sampled`，所以 claim 最多是 `spot_checked`（E-12）：101 个点之间仍可能藏着更深的窄谷。`best_probe` 总是给出探测点中 f 最小的点。`derived.optimum` = `local`。一致性套件核查这个声明：返回的点不是全局极小时，没有这个警告就是虚报。Brent 停在哪个谷取决于迭代路径，所以 golden 不预测 `grid_probe` 成立与否：多谷的用例带 `postcondition_may_fail: ["grid_probe"]`（v0.4.26 新增的 golden 字段，只供参考实现的收据测试使用；运行器不读它），由规则按真值判定警告是否应当出现。
- FB-5 **后置条件 `probe_local_minimum`**：f(x) ≤ f(x ± h)，h = 3·tol1；落在区间外的一侧跳过（极小在端点时，x 离端点在 h 以内，这正是 Brent 在那里给出的精度）。另有 `all_finite`。
- FB-6 **输出与确定性**：`x`、`fval`、`interval`、`final_bracket`（结束时的 [a, b]；f 在其上单峰时极小点在其中，作为误差估计）、`iterations`、`evaluations`（不含探测的 103 次）、`tol_x`、`max_evaluations`、`best_probe`。`platform_bitwise`（超越函数经编入的数学库，EX-4）。

新码：`W.ACCURACY.BETTER_POINT_FOUND`。
