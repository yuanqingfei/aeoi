# 10.31 `calculus.quadrature.integral`：数值积分（v0.4.15）

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`calculus.quadrature.integral` 0.4.0（容差类 T1）。


对应 MATLAB 的 `integral`。真值来自 mpmath `quad`（50 位精度；有闭式的用例另外与闭式交叉核对过），scipy `quad` 只作记录；都不是 MATLAB 的结果。这个算子逼出的规范问题是：**缺省精度是一个约定**。MATLAB 的缺省 RelTol = 1e-6，很多人以为得到的是机器精度。

**规范性条款**

- IN-1 **输入**：f 用 3.15 的表达式写（变量名缺省为 x）；`limits` = [a, b]，可以是 "Inf" / "−Inf"；a > b 时交换两端、结果取负。两端是同一个无穷大时报 `E.VALIDATION.RANGE`（path `/limits`）；有限的 a = b 正常求值，结果为 0。
- IN-2 **容差**（作者决定，2026-11-25）：缺省 rel_tol = 1e-10、abs_tol = 1e-12，比 MATLAB 的 1e-6 / 1e-10 严。两个容差都在结果里回显。停止条件是 Σ误差 ≤ max(abs_tol, rel_tol·|I|)。两个容差都为 0 时，除非误差估计恰为 0，否则会一直细分到子区间上限，按 IN-5 报 `NO_CONVERGENCE`。所以积分值很小时，精度由 abs_tol 决定，golden 用例 `tiny_value_abs_tol` 演示了这一点。
- IN-3 **算法**：全局自适应 Gauss–Kronrod (7, 15)，误差公式同 QUADPACK。
  - 变量替换同 MATLAB integral：有限区间用 x = (a+b)/2 + (b−a)/4·t(3 − t²)，t ∈ [−1, 1]，可以减弱端点奇异；(−∞, ∞) 用 x = t/(1 − t²)，t ∈ (−1, 1)；[a, ∞) 用 x = a + t/(1 − t)，(−∞, b] 用 x = b − t/(1 − t)，t ∈ [0, 1)。被积函数乘以 dx/dt。
  - 初始在 t 上等分 10 段。之后每一步只二分误差估计最大的一个子区间（误差相等时取 t 最小的那个），子区间总数达到 650（同 MATLAB 的上限）仍不满足容差时停止，按 IN-5 报错。子区间的和用补偿求和。
  - 区间端点因舍入映到 ±∞ 时，该点的贡献记为 0：积分要存在，尾部必须趋于 0。
- IN-4 **误差估计**：报告 max(Σ Kronrod 误差估计, 全部子区间再二分一次后积分值的变化)。端点奇异时，前者会偏小：golden 用例 `endpoint_singularity` 上偏小了 10 倍，所以加上后者。后置条件 `refinement_consistent` 要求再二分一次的变化 ≤ 容差。
- IN-5 **达不到容差**（作者决定）：报 `E.NUMERICAL.NO_CONVERGENCE`，`details` 给出当前估计值、误差估计和最难的子区间。附两个 remediation：一个把 rel_tol 放宽到 1e-6 的补丁（须用户确认），一个 `ask_user`（在奇点处分段）。被积函数出现非有限值时报 `E.NUMERICAL.NON_FINITE_EVALUATION`，并给出出问题的 x；被积函数本身有限、乘以 dx/dt 后溢出也按此处理。每一步二分之前先检查这一条，所以同一个请求里它优先于 `NO_CONVERGENCE`。
- IN-6 **确定性**：`platform_bitwise`（经数学库，EX-4）。
