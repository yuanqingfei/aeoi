# 10.2 `control.lti.step`

> AEOI 规范第 10 章的一部分（规范性）。通用规则见 [`spec-v0.4.md`](../spec-v0.4.md)；本文件的条款编号在全规范内唯一。示例与 parity 规格以链接给出，文件本身是规范的一部分。
>
> 算子版本（属于线上契约：`fingerprint.request` 含版本号，4.3 R-3）：`control.lti.step` 0.2.0（容差类 T2）。


对应 MATLAB 的 `step` 与 `stepinfo` 的指标部分。参考值来自 python-control 0.10（`step_response`、`step_info`），不是 MATLAB 的结果。

**规范性条款**（v0.4.21 起编号；之前是“语义要点”，内容相同，只把以前要靠 python-control 源码才能确定的定义写全了）

- ST-1 **离散化**：连续系统用 ZOH 精确离散化：增广矩阵 [[A, B], [0, 0]]·dt 的矩阵指数（Van Loan 1978；expm 用 Higham 2005 的缩放平方 + Padé 13），x_{k+1} = Φx_k + Γ，y_k = Cx_k + D（单位阶跃，零初始状态）。阶跃输入在 ZOH 下没有离散化误差，所以归入 T2。离散系统直接递推 A、B。
- ST-2 **网格**：
  - `uniform`：点数 N = floor(t_final/dt + 1e-9) + 1，t_k = k·dt。dt > t_final 报 `E.VALIDATION.GRID`。离散系统 MUST 满足 |dt − ts| ≤ 1e-9·ts，否则 `E.VALIDATION.GRID`，补丁把 dt 设为 ts。
  - `auto`（发 `W.ACCURACY.AUTO_GRID`，不参与 parity）：
    - 连续系统：渐近稳定时 t_final = clamp(7/min|Re p|, 1e-6, 1e6)，否则 10；dt = max(min(t_final/1000, 0.1/max|p|), t_final/10000)（没有极点时不取 0.1/max|p| 一项）。
    - 离散系统：dt = ts；最大极点模 ρ 在 (0, 1) 内时 t_final = max(7·ts/(−ln ρ), 10·ts)，否则 100·ts。
    - 请求里给了 t_final 就用给的值。
- ST-3 **计算量上限**：N × nu > `limits.max_grid_points` 报 `E.RESOURCE.COMPUTE_LIMIT`。有非零极点时附补丁，把 dt 换成 round(max(0.1/max|p|, t_final/(⌊上限/nu⌋ − 1)), 6 位小数)；另附一个 `ask_user`（缩短 t_final）。返回值个数（返回的采样数 × ny × nu）超过 `limits.max_output_values` 报 `E.RESOURCE.OUTPUT_TOO_LARGE`，附两个补丁：抽样返回 m = max(⌊上限/(ny·nu)⌋, 2) 个点，或只返回指标。这两个检查按上面的顺序进行，所以套用 COMPUTE_LIMIT 的补丁之后，仍可能遇到 OUTPUT_TOO_LARGE（CF-9 只要求补丁消除它针对的那个错误）。
- ST-4 **抽样返回**：`return_samples = decimated` 时取下标 round(k(N − 1)/(M − 1))，k = 0…M − 1，round 是四舍五入、.5 远离 0。
- ST-5 **稳定性与 y∞**：渐近稳定按算出的全部极点判定，连续系统 Re p < 0，离散系统 |p| < 1，不设容差（极点是算出的值；临界情形本来就不可判定，结果中的 `trust.condition` 给出最大实部或最大模）。整个系统不稳定时，全部通道的 info 为 null，发 `W.DOMAIN.UNSTABLE_SYSTEM`。y∞ 取 DC 增益 −C·A⁻¹·B + D（离散系统 C·(I − A)⁻¹·B + D），解线性方程组；奇异或结果非有限时，info 为 null，发 `W.DOMAIN.INFINITE_DC_GAIN`。某通道 y∞ 恰为 0（算出的值）时，该通道 info 为 null，发 `W.DOMAIN.ZERO_DC_GAIN`。
- ST-6 **阶跃指标的定义**（在网格上，不插值；与 python-control 0.10 `step_info` 一致，但下面的文字就是定义，不需要参考那份代码）。记 s = sign(y∞)，rise_time_limits = (lo, hi)，settling_threshold = θ：
  - i_lo = 第一个满足 s·(y_k − lo·y∞) ≥ 0 的下标，i_hi 同理（用 hi）。`rise_time` = t[i_hi] − t[i_lo]；任一个不存在时为 null。
  - K = 最后一个满足 |y_k/y∞ − 1| ≥ θ 的下标；没有这样的点时 settled = 0，否则 settled = K + 1。settled < N 时 `settling_time` = t[settled]，否则为 null，并发 `W.DOMAIN.NOT_SETTLED`。
  - `settling_min` = min(min_{k ≥ i_hi} y_k, y∞)，`settling_max` = max(max_{k ≥ i_hi} y_k, y∞)：**y∞ 也参与取最小、最大**。i_hi 不存在时两者为 null。
  - `overshoot`：y_os = max_k s·y_k，Δ = |y_os| − |y∞|；Δ > 0 时为 |100·Δ/y∞|（%），否则 0。
  - `undershoot`：k_u = s·y_k 最小的第一个下标；s·y_{k_u} < 0 时为 −100·y_{k_u}/y∞（%），否则 0。
  - `peak` = max_k |y_k|，`peak_time` = 取到它的第一个下标的时刻。
  - `steady_state` = y∞，`source: "dcgain"`。
  - 时间类指标相对连续时间真值的误差 ≤ dt。
- ST-7 **输出**：`time`、`y`（ny × nu 个通道，每个 [N] 或抽样后的 [M]）、`info`。info 的每个字段是 `{unit, value}`：`rise_time`、`settling_time`、`peak_time` 单位 s，`settling_min`、`settling_max`、`peak`、`steady_state` 单位 1，`overshoot`、`undershoot` 单位 %。SISO 时 info 是一个对象，MIMO 时是 [ny][nu] 数组，不适用的通道为 null。字段名是 snake_case；python-control 用 CamelCase（`RiseTime` 等），golden 文件沿用 python-control 的名字，比较时按名字对应。
- ST-8 **后置条件与 trust**：`all_finite`（全部样本有限；不成立时 claim 为 `unverified`）。`asymptotically_stable` 与 `auto_grid` 是性质，不是后置条件。终点一致性（逐步递推的 x(t_end) 与一次 expm 直接算的 x(t_end) 的相对偏差）写入 `trust.error_estimate` 作后验估计，是启发式的。连续系统 dt > 0.1/max|p| 时发 `W.ACCURACY.GRID_TOO_COARSE`。
- ST-9 **确定性**：`platform_bitwise`。
